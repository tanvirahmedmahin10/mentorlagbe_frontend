# MentorLagbe — Tuition & Mentorship Platform

## Purpose
MentorLagbe is a full-stack tuition and academic mentorship platform that connects students with tutors across Bangladesh. Students can browse and apply for tuition batches, tutors can create and manage tuition listings, and admins can manage users, approve tuition posts, and monitor subscription payments.

## Key Features
- Role-based authentication with Student, Tutor, and Admin roles using Better Auth.
- Tutor onboarding with academic information and teaching experience.
- Browse, search, and filter tuition batches by subject, class, and teaching mode.
- Students can apply for tuition batches and track application status.
- Tutors can create, update, and delete tuition listings.
- Tutors can accept or reject student applications.
- Admins can approve or reject tuition posts and manage user roles.
- Stripe integration for Student Pro ($10) and Tutor Pro ($15) lifetime subscriptions.
- Profile management with ImgBB image uploads.
- Responsive design with dark and light mode support.
